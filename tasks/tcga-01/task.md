# Genes That Mark the Tumor State

## Content

Which genes most clearly distinguish tumors from nearby normal tissue?

## Deliverables

Submit a CSV file named tumor_markers.csv with cancer type, gene, cohort sizes, effect estimate, uncertainty or significance measure, and direction, plus a Markdown file named methodology.md defining eligible samples, comparisons, ranking rules, findings, and limitations.
