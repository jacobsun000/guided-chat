# Financial Statements That Do Not Add Up

## Content

Which reported financial statements contain totals that do not seem to add up?

## Deliverables

Submit a CSV file named statement_issues.csv containing filer, filing, statement, period, reported total, reconstructed total, difference, units, and issue type, plus a Markdown file named methodology.md documenting calculation rules, tolerances, validation checks, and caveats.

## Dataset path

`datasets/sec_financial_statement_notes`
