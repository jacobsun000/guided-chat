# Why Shipping Feels Expensive

## Content

For which purchases does shipping become unusually expensive relative to what is being bought?

## Deliverables

Submit a CSV file named high_shipping_burden.csv containing the selected orders or segments and their item value, freight cost, and burden measure, plus a Markdown file named methodology.md explaining aggregation choices, thresholds, findings, and multi-item-order caveats.
