# Suspicious Trip Records

## Content

Which trip records look suspicious, and what kinds of data problems might they reveal?

## Deliverables

Submit a CSV file named suspicious_trips.csv containing record identifiers or reproducible row references, anomaly categories, and the values that triggered each flag, plus a Markdown file named methodology.md with detection rules, category counts, manual checks, and false-positive caveats.

## Dataset path

`datasets/nyc_tlc_trip_records`
