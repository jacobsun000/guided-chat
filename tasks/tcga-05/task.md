# Samples That Do Not Fit

## Content

Which samples do not fit the molecular identity their labels imply?

## Deliverables

Submit a CSV file named discordant_samples.csv with sample and patient barcodes, assigned cancer type, anomaly measures, quality evidence, and interpretation, plus a Markdown file named methodology.md defining the expected identity, detection rules, manual checks, findings, and false-positive risks.
