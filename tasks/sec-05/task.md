# Financially Resilient Companies

## Content

Which companies look best prepared to withstand financial stress?

## Deliverables

Submit a Markdown file named report.md identifying and ranking the companies assessed as resilient, defining the peer set and resilience criteria, tracing each conclusion to filing metrics or disclosures, testing at least one alternative weighting or stress scenario, and discussing uncertainty.
