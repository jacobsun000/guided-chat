# Unexpectedly Slow or Expensive Routes

## Content

Which trips or routes are slower or more expensive than a rider might reasonably expect?

## Deliverables

Submit a CSV file named flagged_routes.csv listing each flagged route or trip group and its observed and expected time or cost measures, plus a Markdown file named methodology.md documenting filters, baselines, thresholds, main findings, and limitations.

## Dataset path

`datasets/nyc_tlc_trip_records`
