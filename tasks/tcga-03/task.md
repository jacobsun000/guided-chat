# Expression Signals of Early Progression

## Content

Which gene-expression patterns consistently signal earlier cancer progression?

## Deliverables

Submit a CSV file named progression_signals.csv with genes or signatures, cancer scope, cohort sizes, effect estimates, uncertainty, and validation results, plus a Markdown file named methodology.md covering endpoint selection, censoring, modeling, validation, findings, and caveats.
