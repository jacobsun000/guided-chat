# Companies Improving Profitability

## Content

Which companies appear to be improving their profitability, and which are moving the other way?

## Deliverables

Submit a CSV file named profitability_trends.csv with company identifiers, aligned periods, revenue and profitability measures, changes, and trend classification, plus a Markdown file named methodology.md explaining tag mappings, inclusion rules, main findings, and comparability limitations.
